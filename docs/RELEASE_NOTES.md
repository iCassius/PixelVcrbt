Pixel彩铃激活模块 2.3.0-experimental

- 仅 Google Dialer 作用域，严格适配 mustang / CP3A.260905.009 / Dialer 20148463 / 中国电信。
- 显示彩铃所需配置、Dialer 模块实际响应、IMS 注册、当前早期视频会话及画面更新。
- 为缺失前置、模块未响应、未注册、无会话、无画面提供检查方向。
- 待机不误报媒体成功；实际视频呼叫不冒充语音彩铃；呼叫结束后不保留成功快照。
- 四项配置可在空闲时由 Dialer 权限差量兜底，不要求系统框架作用域。

实验版本：系统通话记录分类仍未修复；没有完成接通后的 ACTIVE、OTA、热拔插与紧急呼叫验收。纹理更新只是显示链路证据，不替代画面内容及通话质量验证。

已验证：本机一次未接听语音彩铃显示；模块实时响应、IMS 注册、视频会话及画面更新检测；挂断与停止电话进程后的状态清除；缺少电话状态权限的提示。49 项策略断言及 GitHub Actions 构建通过。

安装后在 LSPosed 中仅勾选 Google 电话并重新加载电话进程。无需给状态 APK 授予 Root。只读参数检测无需启动电话，实时运行检测需要电话进程加载。签名与本项目已有测试安装保持一致，私钥仅通过仓库 Secrets 使用。
